# Code of Conduct

## Our standard

VibeStick-Codex welcomes people who participate in good faith. Be respectful,
constructive, and considerate. Technical disagreement is welcome; harassment,
personal attacks, discrimination, threats, sexualized conduct, deliberate
disruption, and publication of another person's private information are not.

## Scope

This standard applies to repository issues, pull requests, discussions, code
review, and other spaces where someone is representing the project.

## Reporting

Do not report sensitive conduct or private information in a public issue.
Contact the maintainer privately through GitHub. If the report also concerns a
security vulnerability, use the repository's private GitHub Security Advisory
reporting flow described in `SECURITY.md`.

## Enforcement

The maintainer may edit or remove contributions that violate this standard and
may temporarily or permanently restrict participation when necessary. Reports
will be reviewed as privately and fairly as practical.
